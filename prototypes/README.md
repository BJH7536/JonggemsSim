## 화력쇼 — 수습 윈도우 (p02 코어 추출)

**핵심 명제: 실수 없는 방송이 최악의 전략이다.** 무사고 완성 +40 ≪ 수습 +180~900×배수
≪ 대참사 +1,400×연쇄.

- 3분 생방송, 화구 2개 시작. 모드가 리스크 다이얼: 정석 5%/×1.0 · 속성 25%/×1.8 · 무모 60%/×3.2(해금)
- 사고 4종(수습 윈도우 0.8~4.0초): 키 1~4 또는 버튼으로 수습 — **빨리 반응하라**. 배율은
  사고 유형이 정한다(창이 짧을수록 높음, 최대 ×2.5, 버튼에 실시간 표시). 실패하면 −120(조용히)
- 기름 화재를 놓치면 **대참사**: +1,400×연쇄 시청자 폭등, 화구 12초 파손
- 연쇄 배수: 수습 연속 성공 +0.5 (최대 ×3.0, 5초 무수습 리셋)
- 신선도: 같은 사고 유형 반복 수습은 100→70→45→25→10% 감쇠, 타 유형 2회 수습당 1단계 회복.
  사고는 직전 유형이 2.2배 재발하는 경향이 있어 파밍-차단 긴장이 실제로 발생
- 시청자 = 체력(0명 방송 종료)·점수(종료 시점 수, localStorage 최고 기록)·통화(30,000/90,000/
  350,000명 도달 시 화구 3·무모·화구 4 개방 — 최종 룰셋 이진 탐색 산출치)
- 연출: 캔버스 주방(스포트라이트·모드별 가스 불꽃·김·기포), 사고 4종 개별 연출(과열 적광·
  소금 구름·불기둥·칼 섬광) + 수축 윈도우 링, 대참사 폭발·그을음·수리 아크, 합성음 SFX,
  ON AIR 탈리·연쇄 미터·FX 큐(0.4초 간격)
- **AI 시청자 채팅** (2026-08-06 추가): 트위치식 채팅 컬럼. 페르소나 8종 × 톤별 템플릿이
  게임 이벤트 16종(사고·기름화재·수습·고배율·실패·대참사·완성·언락·도네·연쇄 ×3·마일스톤·
  빈 화구 잔소리·잡담·시작·종료)에 반응. **연출 전용 — 룰 수치에 일절 관여하지 않음**(C3,
  critic 승인 밸런스 보존). PROTOTYPE-SPEC 규약 준수: 사실 슬롯 검증·비반복(<0.72)·폐기·
  `[LLM-INTEGRATION-POINT]`·목업 배지. 첫 반응 120~300ms(스펙 기본보다 빠름 — 실시간
  게임이라 의도), 버스트 1~4줄(대참사 최대)·30k 이상 대형 방송은 +1줄, 잡담 빈도는 시청자
  규모 비례

**검증**: Chrome 실구동으로 조리→완성→언락, 수습 산식(+1,792 실측), 신선도 표시·2회당 회복,
연쇄 리셋, 대참사(+2,100·파손 12초), 세션 종료·신기록 저장·재시작 초기화 전 경로 확인.
독립 검증 2종(code-reviewer 결함 14건, critic 조건부 승인→필수·권장 반영) 통과 —
상세는 `05-hwaryeok-spec.md`의 검증 반영 기록.

**3~4차 라운드 반영**: 동일 SFX 100ms 병합(M2), 이탈 시청자 비례화 0.5%/s(M7), 유형 배율
정규화(L4), 도네 규모 비례(L5). 4차 재스윕에서 "대기 전략은 모든 계수에서 손해(처리량
구조)"가 확인되어 메커닉을 **유형 배율 + 빠른 반응**으로 재정의하고 UI 문구 정정,
M6(실패 연쇄 리셋)은 원본 준거로 롤백, 언락 임계는 최종 룰셋 이진 탐색으로 확정(30k/90k/
350k — critic 최종 승인). **알려진 한계**: 정적 그라디언트 매 프레임 재생성 등 성능
미최적화, 보통 실력은 3분 데모에서 화구 4를 거의 못 봄(스트레치 목표 설계 — 시연 시 감안,
예비안 30k/75k/300k).
