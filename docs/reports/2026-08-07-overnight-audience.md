## 2. SHJ 브랜치 분석 요지

방송 셸 v1(허브·시청자 경제·게임 단위 신선도·정산 리포트) + 게임 3종(화력쇼 이식 /
Giving Up On It / 주머니 괴수) + **LLM 프록시 프로덕션 배포**(Vercel icn1)까지 착지.
관객 영역 코드(`chat.js`·`llm.js`)는 "임시 거처" 표기와 이관 조건(contract 4.6)이
명시되어 소유권 경계가 지켜졌다. 프록시 설계(키 서버 소유·게이트 클라이언트 유지·
전 구간 폴백·이중 비용 캡)는 관객 관점 리뷰에서 이견 없음.

**막힌 곳 1건**: 프록시 `ANTHROPIC_API_KEY` 미설정 → `live:false` (헬스체크 실측 확인).
Vercel 로그인이 필요한 **사람 몫** — `proxy/README.md` 4절의 `env add` 한 단계 남음.

## 3. 결함 발견·수정 — "사실 줄이 조용히 사라지고 있었다"

**증상**: 채팅 버스트의 첫 줄(사실 슬롯 = 숫자 앵커)이 특정 이벤트에서 폐기됨.
주머니 괴수 `risky_hit`·`ultra_hit`·`crit`·`enemy_ko`는 **상시 폐기** — flavor 리액션만
나가고 수치를 말하는 줄이 아예 없었다. `oilfire`·`comeback`·`fall`은 확률적 폐기.

**원인**: 한 이벤트의 사실 템플릿들이 서로 다른 슬롯 부분집합을 쓰는데(예: risky_hit의
3템플릿이 각각 {mv,gain}/{gain}/{dmg}), 게임은 {mv,dmg,gain}을 넘기고 게이트는 "넘긴
슬롯 전부 포함"을 요구 → 어떤 템플릿을 뽑아도 탈락. 기존 compose가 무작위 2회
재시도뿐이라 구제도 안 됐다. flavor는 정상 발화라 selftest·실플레이에서 발견 안 됨.

**수정** (커밋 3개):

1. `803fcbc` fix(chat): compose를 **전 템플릿 셔플 스캔**으로 — 호환 템플릿이 하나라도
   있으면 반드시 찾는다
2. `ef1e99a` fix(games): 슬롯 정합 — pocket 5종·GUOI fall 템플릿 정정(★문구 변경분
   소윤 리뷰 대상), 화력쇼 oilfire는 emit 슬롯 축소(acc가 상수라 제거)
3. `b581f37` test(shell): selftest에 **슬롯 정합 검사 3건** 추가 — 재발 방지. 39/39 통과

수정 후 부스 실측: `아쿠아 캐논 적중 44딜 +1,220!!` 등 사실 줄 정상 발화 확인.

## 4. 신규 산출물

### 4.1 페르소나 부스 (`tools/persona-booth.html`) — 기획 작업대

실제 엔진(`games/shell/chat.js`)·실제 어휘(`games/*/chat-data.js`)를 그대로 사용 —
**부스에서 보이는 그대로 게임에서 나온다.** 게임을 플레이하지 않고 이벤트 버튼으로
반응을 확인한다.

- 게임 3종 탭 · **페르소나 솔로 모드**(그 사람만 말하게) · 실게임 형태의 표본 사실 슬롯
- 연속 재생(버스트 무게 가중 무작위) · 대형 방송 토글
- **엔진 로그**: 발화/폐기 + 폐기 사유(슬롯 누락 / 반복 유사도) — "왜 안 나왔는지"가 보인다
- 실행: 브라우저로 직접 열기(`file://` 동작) 또는 `python -m http.server 8770` →
  `/tools/persona-booth.html`. 어휘 수정 → 저장 → 새로고침이 작업 루프
- Chrome 검증: 사실 줄 발화·솔로·게임 전환·반복 폐기 로그·페이지 콘솔 에러 0건
