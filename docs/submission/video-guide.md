# 플레이 영상 촬영 가이드 (제출물 ②)

> **누구든 이 문서만 보고 찍을 수 있게** 쓴 문서다. 30~60초, 실제 플레이 화면.
> 요건: *"실제 게임 플레이 장면 중심, AI를 이용한 조작·합성이나 타인 영상 도용 불가"*
> (`docs/nan2026-requirements.md`). 즉 **화면 녹화 그대로**면 되고 편집은 컷 정리 정도만.

## 0. 찍기 전 준비 (3분)

1. **브라우저 창을 가로로 크게** — 최소 1600×900. 채팅창이 오른쪽에 보여야 한다(이 게임의 핵심)
2. **https://bjh7536.github.io/JonggemsSim/** 접속 (또는 로컬 `python -m http.server 8770`)
3. **채널을 초기화**하고 시작할지 정한다 — 콘솔에서
   `localStorage.removeItem('jonggems-channel-v1')` 후 새로고침.
   → 깨끗한 상태로 보여주려면 초기화, "채널이 자란 상태"를 보여주려면 몇 판 하고 찍는다.
   **추천: 2~3판 미리 해두고 찍기** (구독자·채널 색깔이 채워져 있어야 시뮬레이터로 보인다)
4. **탭을 활성 상태로 유지** — 백그라운드로 가면 rAF가 멈춰 방송이 정지한다
5. 소리: 합성음 SFX가 있다. 켜고 찍으면 좋지만 필수는 아니다
6. 녹화 도구: Windows `Win+G`(Xbox Game Bar) 또는 OBS. **커서가 보이게** 설정

## 1. 샷 리스트 (약 55초)

> 목표는 하나다 — **"AI 시청자가 내 플레이를 진짜로 보고 있다"가 30초 안에 전달될 것.**

| 구간 | 화면 | 조작 |
|---|---|---|
| **0:00–0:06** | 허브(방송 준비) | 마우스를 천천히 움직여 **채널 색깔 막대**와 게임 카드의 **관객 프로필**을 훑는다. 클릭 전에 잠깐 머문다 |
| **0:06–0:12** | 화력쇼 시작 | 카드 클릭 → 화구 1·2에 **속성** 모드로 요리를 올린다. 채팅에 시작 인사가 뜬다 |
| **0:12–0:22** | **사고 → 수습** | 사고가 뜨면 **숫자 키를 빠르게** 눌러 수습. `+숫자` 팝업과 채팅 폭발이 동시에 터진다. 2~3회 반복 |
| **0:22–0:32** | **기름 화재 방치 → 대참사** | 기름 화재가 뜨면 **일부러 놔둔다**. 폭발·화면 흔들림·시청자 폭등, 채팅이 "ㅋㅋㅋㅋ" 도배 |
| **0:32–0:42** | 방송 리포트 | <kbd>Esc</kbd> 또는 시간 종료. **시청자 추이 그래프 → 원형별 순증감 → 채널 색깔 변화 → 다음 시작 시청자** 순으로 잠깐씩 머문다 |
| **0:42–0:55** | 다른 게임 | 허브 → **주머니 괴수**(또는 GUOI) 시작 → 필살기 한 번. **채팅에 뜨는 얼굴이 아까와 다르다**는 게 보이면 성공 |

**컷 편집 없이 한 번에** 찍는 게 가장 안전하다(도용·합성 의심 여지 0). 55초가 빠듯하면
0:42 구간을 줄이고, 그래도 넘치면 리포트를 5초로 줄인다.

## 2. 꼭 화면에 담겨야 하는 것 (우선순위)

1. **오른쪽 채팅창이 계속 보일 것** — 이게 안 보이면 그냥 미니게임 모음으로 보인다
2. **사고 → 수습 → 채팅 폭발**의 인과가 한 화면에 — 이 게임의 명제다
3. **대참사 순간의 시청자 폭등** — "실수가 콘텐츠"라는 역설
4. 리포트의 **원형별 순증감**과 **채널 색깔** — AI 관객이 시스템이라는 증거
5. 게임을 바꿨을 때 **채팅 성격이 달라지는 것**

## 3. 하면 안 되는 것

- AI로 화면을 만들거나 합성하지 않는다 (요건 위반)
- 남의 영상·이미지를 넣지 않는다
- 자막·나레이션은 넣어도 되지만 **플레이 화면이 중심**이어야 한다

## 5. 문제가 생기면

| 증상 | 원인·대처 |
|---|---|
| 방송이 멈춘다 | 탭이 백그라운드로 갔다. 탭을 활성 상태로 두고 다시 시작 |
| 채팅이 안 뜬다 | 이벤트가 없는 조용한 구간이다. 요리를 올리거나 사고를 기다린다 |
| 채팅 배지가 "로컬 시뮬레이션" | 프록시 미설정 상태. **정상이다** — 규칙 기반 채팅도 완전 동작한다. LLM 라이브로 찍고 싶으면 Vercel 키 설정 후 |
| 사고가 안 난다 | 모드를 **속성**(25%)이나 **무모**(60%, 해금 필요)로. 정석은 5%라 잘 안 난다 |
| 화면이 좁다 | 알려진 문제 (PR #6에서 논의 중). 창을 1600×900 정도로 맞추면 가장 낫다 |
