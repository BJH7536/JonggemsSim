# 공명 모델 — AI 시청자 판정층 설계 (v0.2)

> 상태: **설계 논의 단계 — 구현 착수 전.** 원안: 소윤·정훈 (2026-08-06 밤).
> 형식화와 3방향 적대적 검증(밸런스 스켑틱·원칙 감사관·선행 사례 연구)은 정훈 에이전트.
> §6 미결이 남아 있어 ADR 승격 전이다. 이 문서는 팀 논의 자료다.

## 1. 원안 (원문)

1. 각 페르소나는 흥미도 벡터를 가지게 만들고
2. 게임에서 발생한 이벤트는 전체 페르소나에게 전달된다
3. 그 이벤트를 수신한 페르소나들 중 임계값 이상의 반응을 보인 페르소나가
   노이즈 벡터를 활용해 시청자를 늘린다

## 2. 형식화

- **이벤트는 자극 벡터를 가진다** — 이름 붙은 축 4~6개(위험·파괴·숙련·유머·성취 등,
  기획자가 다룰 수 있어야 하므로 소수·유의미)
- **페르소나는 흥미도(주목 강도)와 호오(평가 방향)를 분리해 가진다** — 안전제일은 위험에
  *강하게 주목하며 부정적으로* 반응한다(비명도 트래픽이다). 프로레슬링의 heat(관심량) vs
  face/heel(정렬) 분리와 동형 — TEW 계열이 20년 상업 검증한 구조
- **공명 = 내적(이벤트 벡터, 흥미도 벡터).** 임계값을 넘으면 반응. 한 계산에서 세 가지가
  나온다: **누가 말하는가**(공명자) · **시청자가 얼마나 변하는가**(공명 총량) ·
  **왜 그렇게 말하는가**(공명한 차원과 호오가 톤을 정함)
- **시청자 수는 원형별 구성 분포가 된다.** 유입은 공명한 원형 쪽으로 쏠린다(유유상종) —
  "무슨 콘텐츠를 하면 누가 모이고, 모인 구성이 다음 보상을 정한다" = **관객 포트폴리오
  관리**가 코어 전략 루프. 실제 방송의 "채널 색깔"의 룰화
- **용어 3종 확정** (전부 "노이즈"라 불리던 것 — 성질이 달라 이름을 가른다):

| 용어 | 내용 | 성질 | 규약 5 위치 |
|---|---|---|---|
| **변이** | 원형에서 시청자 개체가 생성될 때의 영구 편차 (소윤 원안의 의도) | 랜덤·개체에 새겨짐 | 생태 장치 — 단일문화 고착 방지(돌연변이 항) |
| **버즈** | 공명 초과분이 유입을 부르는 증폭 | 결정론 | 뼈대 |
| **지터** | 페르소나 반응의 판마다 잔떨림 (판돈 던전 volatility 승계) | 랜덤·1회성 | 양념 — 상한 필수(결정론 항의 ~15%, 시뮬로 확정) |

구현 노트: 개체 단위 시뮬은 대표 표본(수백)만 돌리고 실제 수는 스케일링 — 변이 효과 유지,
계산량 상수.

## 3. 검증 결과 요약

골격 3요소(흥미≠호오 분리 · 판정층/발화층 분리 · 셸 우선 단계화)는 3방향 모두 보존 판정.
치명·주요 결함과 확정된 완충책:

| 결함 | 내용 | 완충책 |
|---|---|---|
| 치명① "일부러 못하기" | 호오가 유입에 무관여면 사고·대참사가 구조적으로 항상 더 번다 | **호오 게이트**: 부정 공명 유입은 이탈 빠른 뜨내기(heel heat), 부정 관심 지속 시 평판 페널티(X-Pac heat 전환). Idol Manager의 fake scandal 이원 밸런스와 동형 |
| 치명② 단일문화 눈덩이 | 유입 ∝ 구성비 = 복제자 동역학. 시뮬상 8방송 내 95% 고착, 0% 원형은 영구 사멸, 다변화가 체력 손실로 처벌됨 | 구성비 무관 절대 유입항(혼합 바닥) + **길가던행인 = 무원형 완충 풀** 승격 + 변이 + 탐색 보너스 + 혼잡 페널티(단일 원형 60%+ 시 이탈 가속) + 능동 회복 레버(컨셉 방송) |
| 주요③ 침묵 절벽 | 임계값이 발화·보상을 겸하면 저규모 방송이 무음 + 학습 불가 | **임계값 이원화**: 발화 임계(관객 소유·연출 밀도) ≠ 경제 기여 임계(무대 소유·룰 상수), "경제 ≥ 발화" 불변식 |
| 주요④ C3 충돌 | 판정층이 시청자 수를 정하면 "말만 한다" 위반? | **C3 분해**: C3a 주객전도 금지(플레이·난이도 불개입 — 유지) + C3b 비결정 생성물의 경제 유입 금지(발화층·LLM 영구 금지 — 유지). 판정층은 결정론 데이터 + clamp — 판돈 던전 trust→베팅액 선례. 단방향 불변식: 발화층 산출물은 어떤 경로로도 판정층·경제 입력이 될 수 없다 |
| 주요⑤ 기존 밸런스 | 셸 유입과 게임 내 상수의 이중 지불·복리·이중 감쇠 — "상수 안 건드리니 안전"은 산술적으로 성립 안 함 | §6 미결(해소 방향) + 몬테카를로 5차(셸 합성)를 도입 게이트로 |
| 주요⑥ 튜닝 표면 | 파라미터 16개 → 200개+, 비지역 결합 | **공명 샌드박스 툴** 선행 필수 + 경제 원형 4~5종 압축(발화 페르소나 8종은 유지, 다대일 매핑) |
| 주요⑦ 역공학 | 축 4~6개 내적은 수십 판이면 위키화됨 (Game Dev Tycoon 사례) | 숨기지 않는다 — 습관화(시간축)와 구성 상태 의존(상태축)이 정적 최적해를 제거. 수치 노출은 채팅의 서수적 반응으로 한정 |

## 4. 미결 질문 분석 (정훈 질문, 08-07)

### 4.1 이벤트 벡터 태깅에 LLM을 쓰되 파밍이 불가능하게 — 가능하다

부품 고정 내장이 유저 게임의 자율성을 깎는다는 지적은 타당하다. 결론: **"실시간 태깅"이
아니라 "등록 시 1회 태깅 + 구조적 정규화"라면 LLM 태깅을 허용할 수 있다.** 5장치:

1. **자극 예산 정규화 (제로섬)** — 게임당 이벤트 벡터 총량을 고정 예산으로 정규화한다.
   "초위험 대폭발!!" 과장 태그는 자기 게임의 다른 이벤트 벡터를 깎을 뿐 총 유입을 못
   늘린다. 파밍의 이득 원천(총량 부풀리기)이 구조적으로 사라지고, 분포(게임의 색깔)는
   유저 마음대로 — 자율성 보존
2. **1회 태깅 + 동결** — 게임 등록 시점에 태깅하고 버전과 함께 저장, 이후 결정론 데이터.
   재현성·시뮬 가능성 회복, 모델 업데이트로 인한 밸런스 표류 차단. 재태깅은 명시적
   재등록 절차로만
3. **행동 기반 교차 검증** — LLM에게 설명 텍스트만 주지 않고 이벤트의 기계적 텔레메트리
   (실측 발생 빈도·피해량·지속시간)를 함께 준다. 서버 규칙이 "고위험 태그인데 초당 5회
   발생" 같은 모순을 감점 — **빈도-강도 반비례 정규화**(자주 일어나는 자극은 강도가
   낮게 강제된다). 습관화의 등록 시점 버전이다
4. **경제단 clamp** — 태그가 뭐든 이벤트당·방송당 유입 상한은 룰 상수 (판돈 던전 선례)
5. **런타임 습관화** — 같은 자극 반복은 어차피 감쇠. 잔여 파밍 이득 소거

프롬프트 인젝션은 proxy/의 검증된 패턴(서버 소유 프롬프트 + 입력의 데이터 직렬화)을
태깅 엔드포인트에 그대로 적용. 부품 내장안과 배타적이지도 않다 — 부품이 기본 태그를
제공하고 LLM이 예산 안에서 재배분하는 절충이 자율성·안전의 균형점.

### 4.2 게임 내 보상을 상수 대신 시청자 비례로 — 방향은 옳고, 형태는 "저성장 함수 × clamp"

순수 비례(gain = V의 %)의 함정 둘: **복리 폭주**(이득이 V에 비례하면 성장이 지수화 —
이미 도네 +%·이탈 −%가 있는 위에 세 번째 % 항) · **초반 빈사**(V=300에서 5% = +15명,
현행 수습 +520의 손맛 소실). 권장 복합식:

```
gain = base × f(V),   f(V) = clamp((V / V0)^α, 1, K)     α ≈ 0.5, V0 = 시작 시청자
```

- 초반(V ≤ V0): f = 1 → **기존 상수 그대로 = critic 4차 승인의 절대값 보존**
- 성장하면 배율이 완만히 따라온다: V=1,200에서 ×2, V=30,000에서 ×10 (α=0.5, V0=300)
- 지수 폭주 없음(성장률이 갈수록 감쇠), K 상한으로 언락 페이싱 보호
- base 비율(수습 900 : 대참사 1,400)이 그대로 유지 — 4차 승인의 **상대 밸런스 계승**

남는 결정이 §6의 해소 방향과 같은 문제다: f(V)를 셸 버즈의 **대체**로 쓸 것인가(이중
지불 소멸 — 깔끔), **병존**시킬 것인가(둘 다 clamp + 재시뮬). 어느 쪽이든 언락 임계
재탐색(몬테카를로 5차)이 필요하다.

## 5. 도입 게이트 (구현 착수 조건)

1. ADR-002 합의: C3 분해 · 소유권 3층(집계식·clamp = 무대 / 벡터 스키마 = 3자 계약 /
   벡터 값 = 소윤 저작 + 시뮬 게이트) · 단방향 불변식 · **"판정층 데이터는 빌드 타임
   정적이며 런타임에 LLM 출력으로 생성·수정될 수 없다"** (이벤트 태깅은 §4.1 절차로만)
2. 공명 샌드박스 툴 (슬라이더 → 8종 공명·발화·유입 즉시 표시)
3. 몬테카를로 5차 (셸 합성) — 통과 기준: 4차 승인 페이싱 지표(언락 도달 시간 분포·체력
   바닥 확률)가 허용 범위 내
4. 용어 3종(변이·버즈·지터)과 임계값 이원화의 contract 등재

## 6. 미결

- **이중 지불 해소 방향** — (A) 통화 분리(게임 내 상수는 점수로 격리, 시청자는 셸 단독)
  (B) f(V) 대체 (C) 병존 + clamp. 정훈 검토 중 (2026-08-07)
- 경제 원형 압축(4~5종)과 발화 페르소나 8종의 매핑표
- 캐스트 게임 중립화 (contract 4.6 미결과 동일 건 — '10년차주방장'이 등반 방송을 본다)
- 페르소나 판간 기억(관계 변수)과 공명 모델의 결합 시점
- "노이즈 벡터" 원안 의도는 **변이**로 확정 (정훈이 원안 대화의 취지를 확인, 08-07 —
  "한 페르소나에서 생성된 시청자들이 전부 동일하면 단조로워서 넣었다") — §2 용어표 반영 완료
