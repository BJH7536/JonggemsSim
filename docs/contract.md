## v1에 들어갈 것 (목차 예약)

1. **이벤트 스키마** — 게임(무대)이 발행하고 채팅(관객)이 소비하는 단위:
   이름 · 사실 슬롯(키·타입·포맷 규칙) · 버스트 무게 · 발생 맥락.
   참조 구현: `prototypes/05-hwaryeok-show.html`의 `CHAT_T`(이벤트 16종)·`CHAT_BURST`
2. **페르소나 데이터 형식** — `data/personas/*.json` 스키마 (7축 모델 기반).
   참조: `prototypes/05-hwaryeok-personas.md` 4.1
3. **톤 목록** — 현행 6종 (hype/worry/info/mock/cheer/question). 추가·변경은 이 문서 개정으로만
4. **게임↔셸 인터페이스** — 게임 수명주기·이벤트 발행 API (현재 작성, 무대 소유 부분)
5. **검증 규칙** — validate가 검사하는 것: 슬롯-스키마 일치, flavor 최소 개수, 톤 유효성

## 잠정 합의 (v1 전에도 유효)

- 관측 = 이벤트 스트림. 화면 해석 방식 금지
- 사실 슬롯 값은 발화 본문에 그대로 포함되어야 검증 통과 (포맷팅된 문자열 기준)
- 이벤트당 flavor 템플릿 6개 이상 (비반복 게이트 전제)
