# ADR-003: 정훈 부재 기간(8/8~8/9) 상호 리뷰 규약 한시 완화

- 일자: 2026-08-08
- 상태: **확정 — 정훈 결정** (본인 부재를 스스로 예외 처리하는 결정이므로 소급 이의 가능)
- 유효 기간: **2026-08-08 ~ 08-10 제출 시각까지.** 이후 자동 소멸하고 원 규약이 되살아난다

## 배경

정훈이 독감으로 8/8~8/9 이탈했다. 그런데 팀 규약은 두 곳에서 정훈의 리뷰를 요구한다:

- `ADR-001` §공동 소유 — `docs/contract.md`를 바꾸는 PR은 **정훈·현재 상호 리뷰 필수**
- `CONTRIBUTING.md` §브랜치·PR 규칙 1 — `engine/`·`games/`의 **구조 변경**과
  `docs/contract.md` 변경은 **다른 엔지니어 리뷰 후 머지**

두 조항 모두 **부재 시 예외를 두지 않았다.** 그 결과 현재가 올린 PR 7건(#5~#10, #12,
합계 약 +3,058/−185)이 리뷰 대기로 묶였고, #12는 실제로 `contract.md` 4.1/4.3을 바꾼다.

**이게 왜 치명적인가**: GitHub Pages는 `main` 브랜치 자동 배포다(`deploy.md`). 즉
**머지되지 않으면 제출물 ①(플레이 가능한 빌드)에 이 작업이 하나도 없다.** 마지막 배포는
2026-08-07 16:16 UTC였고, 그 이후 게임 2종 추가·데스크탑 허브·아트 32종이 전부 미반영이다.
심사자가 여는 링크는 게임 3종짜리 구버전이다.

## 결정

**부재 기간 동안 위 두 조항의 "다른 엔지니어 리뷰"를 면제하고, 현재의 셀프 머지를 허용한다.**

- 대상: `games/`·`engine/`·`docs/contract.md`를 포함한 무대(현재) 영역 전체
- 권한은 이미 있다 — 현재는 `write` 협업자이고 `main`에 브랜치 보호가 없다.
  **막고 있던 것은 기술적 제약이 아니라 이 규약뿐이었다**
- 관객 영역(`games/shell/chat.js`, 공명 판정층)의 **코어 로직**은 면제 대상이 아니다.
  다만 PR #4 리베이스 과정의 **UI 통합부 이식**은 허용한다 (현재가 #7에 `Shell.archProfile`
  존재 가드를 미리 심어 둔 경로). 코어 보존 여부는 사람 리뷰 대신 **selftest가 검증한다**

## 리뷰를 대신하는 것 (면제이지 무검증이 아니다)

1. `games/shell/selftest.html` **FAIL 0** — 특히 공명 배분·호오·변이·채널 이월 단언.
   여기가 깨지면 리베이스가 코어를 건드린 것이다
2. 배포 후 **라이브 URL 실접속** — 게임 전종 시작·채팅 발화·리포트 렌더
3. 각 PR 본문의 검증 기록 (현재가 이미 첨부)

## 대안 (기각)

- **정훈 회복까지 대기** — 8/9~8/10에 몰리고, 영상 촬영이 머지 뒤에 와야 하므로 연쇄 지연.
  마감을 넘길 확률이 실질적이라 기각
- **정훈 에이전트가 대리 리뷰 후 머지** — 3,058줄을 D-2에 리뷰하는 시간 비용이 크고,
  `showHub()` 충돌 해소 시 남의 화면 설계를 추측해야 한다. 작성자 본인이 더 정확해서 기각
- **규약을 영구 폐지** — 규약 자체는 옳다(에이전트 3대가 서로 다른 진실을 만드는 것을 막는다).
  기간을 한정해 되살아나게 하는 편이 낫다
