# ADR-004: 공명 모델 v1 — 판정층 도입과 C3 분해

- 일자: 2026-08-07
- 상태: **초안 — 정훈 발의, 현재(무대 경계)·소윤(벡터 데이터) 리뷰 대기**
- 배경·검증·완충책 상세: `docs/resonance-model.md` (형식화 v0.2 + 3방향 적대적 검증)
- 일정 근거: 정훈 결정 "사흘 안에 만든다" (마감 8/10) — v1 범위는 아래 §스코프로 한정

## 결정 1 — C3는 재정의하지 않고 분해한다

- **C3a 주객전도 금지 (유지)**: 시청자는 플레이·난이도·게임 내부 규칙에 절대 개입하지 않는다
- **C3b 비결정 방화벽 (유지)**: LLM·랜덤 발화 등 비결정 생성물은 경제에 유입될 수 없다.
  발화층의 산출물이 판정층·경제의 입력이 되는 코드 경로는 존재해서는 안 된다 (단방향 불변식)
- **판정층 (신설 허용)**: 결정론 데이터(벡터·임계값) + clamp된 집계식은 경제에 관여할 수 있다.
  판돈 던전의 trust→베팅액 clamp 선례를 따른다
- **판정층 데이터는 빌드 타임 정적이다.** 런타임에 LLM 출력으로 생성·수정될 수 없다.
  이벤트 자극 벡터의 LLM 태깅은 "등록 시 1회 + 자극 예산 정규화 + 동결" 절차로만
  (`resonance-model.md` §4.1) — 위반 지적 권한은 관객(ADR-001 관례)

## 결정 2 — 이중 지불 해소: "총량은 건드리지 않는다. 공명은 배분만 한다" (확정)

셸이 별도의 버즈 유입을 만들지 않는다. **총량은 현행 그대로**
(`총량 = 이벤트 상수 × 게임단위 신선도` — critic 4차 승인 상태 무변경),
공명 프로필은 그 유입이 **어느 시청자 원형으로 가는지(배분)** 만 정한다.

- 이중 지불이 원천적으로 없다 (유입 채널이 하나뿐)
- 배분 가중치에 현재 구성비를 곱하지 않는다 → 복제자 동역학(단일문화 눈덩이) 원천 회피
- **총량 무변경이므로 승인 밸런스가 100% 보존된다 — 몬테카를로 재실행이 불필요하다**

### f(V) 규모 배율은 v1에서 제외 (정훈 결정, 08-07)

검토했던 `f(V) = clamp(√(V/300), 1, K)`(시청자 규모에 따라 이벤트 보상을 키우는 배율)는
넣지 않는다. 근거:

- 화력쇼는 **언락이 시청자 수 기반**(3만/9만/35만)이라, 보상 배율을 조금이라도 바꾸면
  언락 도달 시점이 반드시 움직인다 — "약하게 넣기"가 구조적으로 불가능하다
  (K=2는 V=1,200에서 상한에 닿아 사실상 '상수 2배'이고, 임계도 2배로 올리면 실질 변화 0)
- 의미 있는 K(≈8)는 4차 이진 탐색으로 잡은 언락 임계 3개의 전면 재탐색을 요구한다
- 해결하려던 문제(후반에 실력 보상이 규모 대비 작아져 도네가 커 보이는 것 — 규약 5 역전)는
  **3분 데모 구간에서 거의 드러나지 않는다** (보통 실력은 3만~9만 구간에 머문다)
- 배분층과 완전히 독립이라 언제든 나중에 얹을 수 있다 → **본선(9월) 백로그**

## 결정 3 — 임계값 이원화

발화 임계(관객 소유 — 채팅 활기 튜닝 자유) ≠ 경제 기여 임계(무대 소유 — 룰 상수).
불변식: 경제 임계 ≥ 발화 임계. 연출 튜닝이 경제를 흔들 수 없다.

## 결정 6 — 채널 계층: 관객 구성은 방송 간에 이월된다 (2026-08-08 추가)

판정층만으로는 **방송이 끝나면 관객이 증발**한다. 구성이 매 방송 초기화되면 10번째 방송이
1번째와 똑같아지고, "어떤 콘텐츠를 하면 어떤 시청자가 모이고 그 구성이 다음을 정한다"는
공명 모델의 목적 자체가 성립하지 않는다. 그래서 채널 계층을 둔다.

- **`ch.mix`** — 채널의 관객 구성 비율(합 1). 방송 종료 시
  `mix ← mix×(1−0.45) + 최종구성비×0.45`로 물든다. 1.0(완전 대체)이면 마지막 방송이 색을
  통째로 갈아엎어 "정체성"이 아니라 "최신 방송 표시"가 된다 — 0.45면 같은 장르 2~3회에
  확실히 물들고 한 번으로는 안 뒤집힌다 (실측: 대참사 방송 1회 후 뜨내기 채널 유지,
  2회째에 불구경파 채널로 전환)
- **방송 시작 구성 = `ch.mix × 시작 시청자`** — 채널의 색을 물려받는다
- **시작 시청자 = 게임 기본값 + clamp(구독자 × 0.4, 0, 700)** — 채널이 커질수록 출발선이
  높아진다. **총량에 닿는 유일한 조각이라 상한이 필수**다 (언락 페이싱 보호)
- **고착 위험 없음**: 배분에 구성비 곱이 없으므로(결정 2) 불구경파 채널에서도 숙련 콘텐츠는
  분석가를 정상 유입시킨다. 실측으로 "분석가 방송 3회면 색이 돌아온다"를 selftest에 고정
- UI: 허브·리포트의 채널 색 막대 + "다음 방송 시작 시청자". 채팅 캐스팅이 이미 구성을
  반영하므로 **다음 방송을 켜자마자 채팅의 성격이 다르다** — 추가 구현 없이 따라온다

## 결정 7 — 호오·변이·탐색 보너스로 모델을 완성한다 (2026-08-08 추가)

결정 2·6까지는 "흥미도만 있는 공명"이었다. 원안과 검증에서 핵심으로 꼽혔던 세 조각을 넣어
모델을 닫는다.

**① 호오(valence)** — 원형마다 축별 감정 방향(−1~1)을 갖는다. 흥미도가 "얼마나 주목하나"라면
호오는 "어느 쪽으로 반응하나"다. 안전제일은 위험에 강하게 주목하며 **부정적으로** 반응한다 —
하나로 뭉개면 이 사람은 위험 이벤트에 무반응이어야 한다. 프로레슬링 heat/정렬 분리와 동형.
- **쓰임: 유입의 질.** 부정 공명으로 온 몫은 **뜨내기**로 분류되어 초당 1.5%씩 빠져나간다
  (반감기 ≈ 46초). "야유·논란은 트래픽을 부르되 남지 않는다"는 실제 방송 생리
- ⚠ **총량에 닿는 변경이다.** 대참사 유입의 8%가 이탈한다(90초 기준 실측). 게임 명제
  (완성 40 ≪ 수습 900 ≪ 대참사 1291)는 유지되며 selftest가 이 순서를 고정한다.
  덤으로 "고의 대참사 파밍"이 약간 억제된다 — 검증에서 지적됐던 항목

**② 변이(mutation)** — 배분된 몫의 12%가 성향이 가까운 이웃 원형으로 태어난다(총량 보존).
소윤 원안("한 원형에서 나온 시청자가 전부 같으면 단조롭다")의 집계 근사이자, **구성비 0인
원형이 영원히 되살아나지 못하는 흡수 상태**를 없애는 장치. 근접도는 흥미도 벡터 코사인.
중립(미태깅) 유입에는 적용하지 않는다 — 신호 없는 드리프트를 만들기 때문.

**③ 탐색 보너스** — 방송 종료 시 구독자 획득에 다양성 배수를 곱한다
(`구독자 = 최종/100 × (1 + 0.6 × 정규화 엔트로피)`). **방송 중 시청자 수에는 손대지 않아**
승인 밸런스와 충돌하지 않으면서, 채널 색을 관리할 이유가 처음으로 생긴다. 이게 없으면
관객 구성은 관찰 가능한 장식일 뿐 전략이 아니다.
