# ADR-009 — 임팩트 계층: 설계 피크에 강한 피드백(클래식 스팅 + 대형 스탬프 + 폭죽)

- 일자: 2026-08-09
- 상태: **사용자 승인 — 설계 확정.** 구현 착수
- 발의: 사용자 지시 — *"게임 내적으로 피드백이 약하다. 시청자 수가 확 튀거나 giving에서
  대추락(대참사)이 일어나는 등의 사건이 일어날 때 강한 피드백이 오게 변경해야 한다.
  특정한 브금(암울한 클래식, 밝은 클래식)이 나오게 하는 등 피드백이 필요해."*
- 관련: 공통 설계 규약 2(손실 무연출)·3(0.4초 간격 큐) · C3(관측 전용) ·
  ADR-004(공명 판정층 — `CAM_MOOD` 출처) · `Shell.CLIP`(같은 `BURST` 신호를 쓰는 선례)

---

- **무엇을**: 게임의 **설계 피크**(버스트 무게 4)와 **시청자 급등**(유입 30%↑)에 2~3초짜리
  임팩트를 건다. 암울/밝음 두 갈래 — 공개 도메인 클래식 모티프를 WebAudio로 합성하고,
  대형 스탬프·폭죽·채팅 폭주를 함께 얹는다.
- **왜**: 지금 큰 사건과 작은 사건의 연출 차이가 `flash(.18)` 대 `flash(.5)` 정도다.
  화면이 흔들리고 스탬프가 뜨지만 **소리가 같아서** 사건의 크기가 귀로 안 들어온다.
  종겜스의 도파민 루프는 "실력 연동 스파이크가 뼈대"(규약 5)인데 그 뼈대가 밋밋했다.
- **핵심 원칙 — 새 저작 테이블을 만들지 않는다**: 언제·어느 쪽인지를 이미 있는 신호
  세 개가 전부 답한다. 새 게임이 기존 이벤트 이름을 쓰면 임팩트는 공짜로 따라온다.

---

## 1. 판정 — 이미 있는 신호 3개

### ① 언제 (트리거 2종)

| 트리거 | 출처 | 조건 |
|---|---|---|
| 사건 피크 | `stage.emit(ev)` | `Chat.BURST[ev] === 4` |
| 시청자 급등 | `stage.gain(n)` | `n >= viewers × Shell.DON.BURST` (0.30) |

버스트 무게 4는 **기획이 저작한 "이 순간의 크기"의 최댓값**이다. 클립 흥미도
(`Shell.interestScore`)가 이미 같은 신호를 쓴다 — 임팩트가 새 문턱을 발명하면 두 개의
"큰 순간" 정의가 생겨 서로 어긋난다. 5게임이 전부 무게 4를 하나 이상 갖고 있다:

| 게임 | 암울 (panic) | 밝음 (aha) |
|---|---|---|
| 화력쇼 | `disaster` | — |
| Giving Up On It | `fall_legend` | `summit` |
| 해체쇼 | `boom` | `defused_clutch` |
| 심연낚시 | `line_snap` | `land_legend` |
| 주머니 괴수 | — (2026-08-10 `wipe` 승격안 계측 기각 — ADR-010) | `comeback` |

급등 문턱은 `Shell.DON.BURST`를 재사용한다. 셸이 이미 "대참사급 = 시청자의 30%가 한 번에
움직임"으로 쓰는 값이라, 사건 도네와 임팩트가 **같은 순간을 가리킨다**.

### ② 어느 쪽 (방향)

`Shell.CAM_MOOD` 재사용 — 스트리머 캠 표정을 위해 이미 모든 이벤트를 분류해 둔 표다.

- `panic`·`confusion` 계열 → **암울**
- `aha` 계열 → **밝음**
- 시청자 급등 → **밝음** (유입은 언제나 좋은 일이다)

위 8개 피크가 전부 이 표에 이미 들어 있다. 분류에 없는 이벤트는 임팩트 없음 — 조용히.

### ③ 순수 함수로 떼어낸다

```
Shell.impactOf(ev, burst) → 'bright' | 'dark' | null
```

조용히 틀리면 대참사에 팡파르가 울린다. selftest가 8개 피크를 못박는다.

## 2. 연출 4종

### 오디오 — 공개 도메인 모티프, payload 0바이트

배포 payload 여유가 165KB(2,535/2,700KB)뿐이라 음원 파일은 불가능하다. 30초 MP3 한 개도
못 들어간다. 기존 `Shell.sfx.tone`(WebAudio 합성)으로 **연주**한다 — 새 오디오 계층 없음.

- **암울**: 베토벤 교향곡 5번 1악장 동기 (G-G-G-E♭) → 하강 아르페지오. 약 2.4초
- **밝음**: 환희의 송가(베토벤 9번) 첫 소절 → 상승 팡파르. 약 1.8초

둘 다 공개 도메인이고 첫 음에 알아들을 수 있다는 게 선정 이유다. "무슨 곡인지 몰라도
분위기는 안다"가 아니라 **"어, 운명이다"**가 목표다.

### 시각 3종 (사용자 선택)

- **대형 스탬프** — 기존 `#bigStamp`에 `.mega` 클래스만 얹는다 (새 DOM 0개). 게임이 같은
  박자에 자기 문구를 던지면(GUOI `25m 대추락`) 그걸 크게 쓰고, 없으면 방향별 기본어.
- **폭죽** — 캔버스 파티클. **밝은 사건에만.** 대참사에 폭죽은 조롱이 된다 (규약 2의 정신).
- **채팅 폭주** — 사건 뒤 3초간 버스트가 두꺼워진다. 기존 `Chat.heat`를 올려서 처리하므로
  엔진 수정 없음.

## 3. 경계

- **규약 2 (손실 무연출)**: `loseViewers` 경로에는 아무것도 붙이지 않는다. `donSpike`는
  급락에도 걸리지만 임팩트는 **유입에만** 건다. GUOI 대추락은 시청자 손실이 아니라 **플레이
  사고**이므로 암울 스팅 대상이 맞다 — 사고도 콘텐츠다.
- **규약 3 (0.4초 간격)**: 임팩트 전용 쿨다운 6초. `DON.FORCE_GAP`(3초)보다 길게 잡아
  연쇄 피크에 두 곡이 겹치지 않게 한다. 곡이 물릴 바에는 두 번째를 버린다.
- **C3**: 전부 연출이다. 시청자·코인·등급·도감 어디에도 닿지 않는다. 판정은 관측만 읽는다.
- **규약 5**: 트리거가 버스트 무게(기획 저작)와 실제 유입량이라 **뼈대에만 걸린다.**
  랜덤 도네(무게 2)는 문턱을 넘지 못한다 — 양념은 임팩트를 못 산다.

---

## 4. 배치

새 파일 `games/shell/impact.js` — `Shell.Impact.fire(kind, text)` 하나가 표면이다.
셸은 훅 두 줄(`emit`·`gain`)만 갖는다. 폭죽 파티클은 셸의 draw 루프가 그린다.

shell.js가 이미 2,500줄이라 임팩트 연출까지 넣으면 "무대"가 한 파일에서 안 읽힌다.
`dex.js`·`clips.js`·`crowd.js`와 같은 분리 방식이다.

## 5. 검증

- selftest: `Shell.impactOf`가 8개 피크를 정확히 가르는가 / 무게 3 이하는 `null`인가 /
  쿨다운이 연속 호출을 막는가
- 실주행: GUOI 대추락과 정상 등반에서 각각 다른 곡이 나오는가, 폭죽이 밝은 쪽에만 뜨는가
