# ADR-002: 공명 모델 v1 — 판정층 도입과 C3 분해

- 일자: 2026-08-07
- 상태: **초안 — 정훈 발의, 현재(무대 경계)·소윤(벡터 데이터) 리뷰 대기**
- 배경·검증·완충책 상세: `docs/resonance-model.md` (형식화 v0.2 + 3방향 적대적 검증)
- 일정 근거: 정훈 결정 "사흘 안에 만든다" (마감 8/10) — v1 범위는 아래 §스코프로 한정

## 결정 1 — C3는 재정의하지 않고 분해한다

- **C3a 주객전도 금지 (유지)**: 시청자는 플레이·난이도·게임 내부 규칙에 절대 개입하지 않는다
- **C3b 비결정 방화벽 (유지)**: LLM·랜덤 발화 등 비결정 생성물은 경제에 유입될 수 없다.
  발화층의 산출물이 판정층·경제의 입력이 되는 코드 경로는 존재해서는 안 된다 (단방향 불변식)
- **판정층 (신설 허용)**: 결정론 데이터(벡터·임계값) + clamp된 집계식은 경제에 관여할 수 있다.
  판돈 던전의 trust→베팅액 clamp 선례를 따른다
- **판정층 데이터는 빌드 타임 정적이다.** 런타임에 LLM 출력으로 생성·수정될 수 없다.
  이벤트 자극 벡터의 LLM 태깅은 "등록 시 1회 + 자극 예산 정규화 + 동결" 절차로만
  (`resonance-model.md` §4.1) — 위반 지적 권한은 관객(ADR-001 관례)

## 결정 2 — 이중 지불 해소: "총량은 상수×f(V), 배분은 공명" (잠정)

셸이 별도의 버즈 유입을 만들지 않는다. 기존 검증된 이벤트 상수가 **총량**을 정하고
(`총량 = 상수 × 게임단위 신선도 × f(V)`, `f(V) = clamp(√(V/V₀), 1, K)`),
공명 프로필은 그 유입이 **어느 시청자 원형으로 가는지(배분)** 만 정한다.

- 이중 지불이 원천적으로 없다 (유입 채널이 하나뿐)
- 배분 가중치에 현재 구성비를 곱하지 않는다 → 복제자 동역학(단일문화 눈덩이) 원천 회피
- critic 4차 승인의 상대 밸런스(수습:대참사 비율 등)가 그대로 계승된다
- 초반(V ≤ V₀=300)은 f=1이라 승인된 절대값과 완전 동일
- **f(V) 도입은 성장 곡선을 바꾸므로 몬테카를로 5차(언락 페이싱 재탐색)가 머지 게이트다**

## 결정 3 — 임계값 이원화

발화 임계(관객 소유 — 채팅 활기 튜닝 자유) ≠ 경제 기여 임계(무대 소유 — 룰 상수).
불변식: 경제 임계 ≥ 발화 임계. 연출 튜닝이 경제를 흔들 수 없다.

## 결정 4 — 소유권 3층 (ADR-001 확장)

| 층 | 소유 |
|---|---|
| 집계식·clamp·f(V)의 K·경제 임계 | 무대 (현재) |
| 벡터 스키마 (축 정의·개수·범위) | 3자 계약 (contract.md) |
| 벡터 값 (원형 흥미도·이벤트 자극) | 기획 (소윤) 저작 — 시뮬 게이트 통과가 머지 조건 |

## 결정 5 — 용어 3종

**변이**(시청자 개체 생성 시의 영구 편차 — 다양성 유지 장치) /
**버즈**(공명 초과분의 결정론 증폭 — v1 미도입, v2 후보) /
**지터**(반응의 판마다 잔떨림 — 양념, 상한 필수). "노이즈"라는 단어는 코드·문서에서 금지.

## v1 스코프 (사흘 — 상세 사양은 resonance-model.md §7)

포함: 자극 축 4종 · 경제 원형 4종(발화 8종 다대일 매핑) · 구성 분포 상태 · 공명 배분 ·
f(V) · 구성 게이지 UI · 리포트 원형별 요약 · 채팅 캐스팅의 구성 반영(연출층) ·
공명 샌드박스 툴 · 몬테카를로 5차.

제외 (v2 백로그): 버즈 증폭 · 호오 기반 유입 질(뜨내기/정착) · 변이 개체 시뮬 ·
관계 변수(판간 기억) · LLM 태깅 파이프라인(유저 제작 게임과 함께).

## 대안 (기각·보류)

- (A) 통화 분리(게임 상수를 점수로 격리) — 게임 3종 전면 재작업 + 4차 승인 자산이
  시청자 축에서 무의미해짐. D-3에 부적합, 기각
- (C) 셸 버즈 병존 + clamp — 이중 감쇠·이중 지불 관리 비용과 재시뮬 부담 최대, 기각
- 유입 배분에 구성비 곱(원안의 유유상종) — 복제자 동역학 실증(8방송 95% 고착)으로 v1 제외,
  완충책 갖춘 v2에서 재검토
