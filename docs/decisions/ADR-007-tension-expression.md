# ADR-007 — 텐션 + 스트리머 표현 축 (시뮬 레이어 v0.2 §6.4·§7)

- **무엇을**: ① 텐션 — 스트리머 컨디션 0~100 (`games/shell/dex.js`, `jgs-dex-v1`에 동거).
  방송 −12 · 같은 게임 연속 −18 · 안 하던 게임 첫 방송 +8 · 휴방(허브 버튼) +25.
  효과는 **파장 대역폭 하나뿐**: `waveMult = 1 + 0.15 × min(파장, 8) × (0.4 + 0.6 × 텐션/100)`.
  30 이하로 방송을 켜면 `streamer_fatigue` 태그가 자동 발행된다 (§7.2 효과②).
  ② 스트리머 표현 축 — 방송 중 리액션 버튼 4종(비명/환호/자조/침묵, `#reactBar`)이
  `streamer_scream/joy/selfmock/silence` 태그를 발행한다. 쿨다운 6초, 마우스 전용
  (게임 3종 키 입력과 무충돌 — v0.2 §11.4). 캠이 표정으로 응답한다 (연출).
- **왜**: v0.2 §6.3의 결정적 발견 — `streamer_*` 8종 = 전체 trigger의 21.1%, Q1·Q3(사람 축)에
  전부 몰려 있는데 발생 수단이 0이었다. 표현 축이 열리면 도달 가능 개체가 92/100 → 99/100.
  텐션은 §7.1 원칙(시청자 수를 절대 깎지 않는다 — 규약 1·2 무접촉)으로 F(텐션) 옵션의
  페널티 위험을 무력화한 형태다. 번아웃도 콘텐츠다 (§7.3) — fatigue trigger 개체는 전원
  Q1이라, 지친 방송이 Q1 전용 칸을 여는 유일한 열쇠가 된다.
- **규칙 준수**: 표현은 플레이어 입력 = 관측 가능한 사건. 관객은 관측하고 말만 한다 (C3 유지).
  판정은 결정론 (C3b). 텐션·파장 전부 메타 통화(구독자 전환)에만 닿는다. 수치는 전부
  v0.2 §7.2의 미검증 초기값 — 표 밖의 새 파라미터를 만들지 않았다 (주요⑥ 튜닝 표면 동결).
- **미결 (팀)**: ① 스트리머 발행 이벤트 계열의 contract 1절 등재 (v0.2 §11.2-1 — 정훈·현재
  공동. 현재 구현은 `streamer_*` 접두 규약으로 판정층에만 들어가고 채팅 어휘에는 없다 —
  어휘가 생기면 시청자가 리액션에 "말"로도 반응한다) ② 공약 선언(`streamer_promise`)·틸트·
  클립 언급(`streamer_story`)·설명 부재 감시(`explanation_absent`)는 후속 ③ 현 로스터에
  fatigue trigger 보유 개체가 없다 — 100종 영입 확장(§5.2) 시 자동으로 살아난다.
- **저장**: `jgs-dex-v1`에 `tension`·`played`·`lastGame` 필드 추가 (구 저장분은 기본값 이월).
