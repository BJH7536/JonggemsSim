# ADR-006 — 반응 도감·파장·캐스트 해금 (시뮬 레이어 v0.2의 최소 실장)

- **무엇을**: ① 반응 도감 — 칸 = (개체, 이벤트), 이벤트 발생 + trigger/repellent **결정론
  판정**이 칸을 연다 (`games/shell/dex.js`, 데이터는 `data/dex.js`). ② 파장 — 이번 방송의
  신규 칸 수. 구독자 전환에만 곱해진다: `newSubs × (1 + 0.15 × min(파장, 8))`. ③ 해금 —
  구독자(시청자 파생)·코인(도네 파생)을 **소비**해 캐스트 6종(시트 4.2 후보) 영입, 영입
  즉시 채팅 캐스트 합류 + 도감 칸 확장. 루프: 방송→반응 칸→파장→구독자→영입→도감 확장.
- **왜**: 시뮬 레이어 설계안 v0.2 §5·§8의 D(커리어 해금) 코어. 사용자 지시(2026-08-09)
  "페르소나 반응 + 시청자수·도네 기반 점진 해금을 프레임워크로".
- **규칙 준수**: 판정은 결정론이고 발화 성공 여부와 무관 (C3b — v0.2 §5.3). 파장은 메타
  통화(구독자)에만 — 방송 중 시청자 수 무관여 (다양성 배율 ADR-004 결정 7과 같은 원리).
  해금은 전부 선택지 개방 — 시작 시청자↑·배율↑·임계↓·벌칙↓ 금지 목록(§8.4) 준수.
  파라미터는 축당 2개 동결: WAVE_RATE 0.15 · WAVE_CAP 8 (주요⑥ 튜닝 표면 방지).
- **태그 대신 이벤트 이름**: 36태그의 원본(`viewer_personas_100_v02.json`)이 아직 레포에
  없다. 칸의 태그 자리를 이벤트 이름이 임시로 맡고, 100종 JSON 착지 시 태그로 승격한다 —
  스키마는 그대로, 값만 바뀐다. validate가 "모든 칸 도달 가능"(§11.3)을 이벤트 합집합으로 검사.
- **보류한 것**: 텐션(§7) — 수치 전부 미검증 초기값 + 휴방 UI 부재. 파장 배율 하나로 루프가
  닫히므로 뒤로 미룬다. 발화 캐스팅과 판정의 결합(트리거된 개체가 우선 말하기)은 arch 가중
  캐스팅(ADR-004 §7.2)과의 조율 필요라 미결 — 지금은 영입 캐스트가 캐스팅 풀에 합류하는
  것으로 "새 목소리"가 들린다.
- **저장**: localStorage `jgs-dex-v1` = { hired, cells }. 부스는 dex를 로드하지 않는다
  (도감은 셸 경제와 붙은 무대 기능).
