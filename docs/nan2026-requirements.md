# NAN 2026 사전과제 요건 — 원문 정리

> 출처: https://nan2026.nhn.com/ (2026-08-06 확인, "사전 과제 제출물 안내" 모달 + FAQ 전문).
> 심사 기준·배점은 **미공개**. 팀 3인 전원의 작업 기준선이므로 임의 수정 금지 —
> 공식 페이지가 갱신되면 확인 일자와 함께 갱신할 것.

## 일정

| 단계 | 일자 |
|---|---|
| **접수·사전과제 마감** | **2026. 08. 10** |
| 참가 팀 발표 | 2026. 08. 22 (개별 안내) |
| 본선 | 2026. 09. 04 – 09. 06, 판교 NHN 플레이뮤지엄 |

본선은 **48시간 무박·전일 참여 필수**, **현장에서 주제 공개** 후 개발. 온라인 참여 불가.

## 참가 규정

- 만 19세 이상 누구나 (학생·타사 재직자·프리랜서 가능). 총 10팀 선발
- **팀당 최대 3인.** 팀원 구성은 원칙적으로 변경 불가
- 유료 API 사용료는 **참가자 본인 부담**. NHN은 행사장 Wi-Fi·전원만 제공
- 저작권은 참가자 귀속. 단 수상작은 접수 시작일로부터 1년간 NHN이 홍보 목적 무상 이용 가능

### 1. 플레이 가능한 빌드 및 소스 코드 (GitHub)

심사자가 직접 플레이할 수 있는 형태. 아래 중 한 가지 이상:

- **웹 빌드: GitHub Pages 등으로 배포하여, 링크 클릭만으로 브라우저에서 바로 플레이**
- 모바일 앱: APK 파일 또는 테스트 배포 링크

- 별도 유료 라이선스 없이 심사자가 실행할 수 있어야 함
- 보안상 PC 실행 파일(.exe 등) 직접 제출은 받지 않음
- 게임 전체 소스 코드를 동일 저장소에 포함하고 **커밋 기록을 유지**
- 저장소는 공개(public) 권장. 비공개 시 심사 계정 `dl_gameai_reviewer@nhn.com` 초대

### 2. 플레이 동영상 (YouTube)

30~60초 분량, **실제 게임 플레이 장면을 중심으로** 제작.

- 영상에 **AI를 이용한 조작·합성이나 타인 영상의 도용은 불가.** 실제 플레이 화면 그대로
- 공개 또는 일부 공개(링크 공유) 상태로 업로드

### 3. 게임 소개 및 설명 문서 (PDF)

- 게임 제목 및 한 줄 소개
- 게임 방법: 목표·조작·종료 조건 포함
- 실행 방법: 게임 설치 및 실행 방법
- 플레이 링크 또는 설치 방법(웹 URL / APK·테스트 링크)
- 플레이 영상 링크

### 4. AI 활용 기술 문서 (PDF)

- AI 활용에 대한 기술적 설명 (예: 구조 설명, **AI 대상 주요 프롬프트 및 지시 사항**)
- 외부 에셋 / 오픈소스 출처

### 5. 팀원 롤 기술서 (PDF)

- 팀원별 이름 / 담당 역할 (기획·개발·아트·AI 활용 등)
- 각 팀원이 실제로 맡아 구현한 영역
- (해당 시) 협업·분업 방식

## 유의사항 (원문)

- 타인의 저작물·아이디어를 무단 도용한 경우, 발생하는 모든 책임은 제출자 본인에게 있으며 선발이 취소될 수 있음
- 외부 에셋(이미지·사운드 등) 사용 시 출처와 라이선스를 AI 활용 기술 문서에 반드시 명시
- AI 도구 사용은 허용·권장하나, 사용 도구와 활용 내역을 반드시 기재
- 제출 링크(GitHub·YouTube)는 **심사 종료 시점까지 접근 가능한 상태로 유지**
- **접수 마감 후에는 제출 내용을 변경할 수 없음**
- 개인정보 수집·이용 및 저작권 관련 동의가 제출에 포함됨

## 대회 프레이밍 (심사 관점 힌트)

> "AI를 활용하는 사람은 많습니다. 우리가 찾는 사람은 AI의 다음 단계를 설계할 디렉터입니다."

AI를 개발 도구로 쓴 것만으로는 차별점이 되지 않는다는 신호. 종겜스는 AI를
**게임 메커닉 자체(관객)** 로 쓰므로 이 축에서 서술할 것 — 4번 문서의 핵심 논지.
